ClassiFash – Refining Style through AI Innovation 👗🤖
ClassiFash is a deep learning-based image classification project that aims to identify and categorize fashion items into 10 distinct categories using a Convolutional Neural Network (CNN). With a focus on improving generalization and minimizing overfitting, dropout layers were strategically applied, leading to a performance boost in model accuracy.

📌 Project Highlights
🔍 Problem Statement: Automatically classify fashion images into one of 10 categories.

🧠 Model Used: Deep Convolutional Neural Network (CNN).

📉 Performance: Improved test accuracy from 91% to 93% after implementing dropout.

⚙️ Tech Stack: Python, TensorFlow, Keras, Numpy, Pandas, Matplotlib

💡 Outcome: Enhanced model generalization and robustness for real-world fashion data.

🗂️ Dataset
Source: Fashion MNIST

Classes: T-shirt/top, Trouser, Pullover, Dress, Coat, Sandal, Shirt, Sneaker, Bag, Ankle boot

Train/Test Split: 60,000 training images and 10,000 testing images

🏗️ Architecture Overview
3 Convolutional layers

MaxPooling layers for downsampling

Dropout layers for regularization

Flatten + Dense layers for classification

Output layer with Softmax activation (10 classes)

📈 Results

Metric	Before Dropout	After Dropout
Test Accuracy	91%	93%
Overfitting	High	Reduced
